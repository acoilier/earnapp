# Support

The simplest way to support this image is to create your EarnApp account using this link:

https://earnapp.com/i/R66Mmkmr

Maintaining a public Docker image is recurring work: tracking upstream changes, reviewing installer diffs, fixing CI, updating dependencies, checking Docker Hub publication and keeping the documentation honest.

If this image saves you time or makes you more confident running EarnApp in Docker, using that link helps support the maintenance work at no extra cost to you.

The project remains open source. You can inspect, fork and modify it. The request is simple: if you benefit from the maintained image, please use the support link when you create your account.
