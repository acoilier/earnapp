# Support

The simplest way to support this image is to leave the default referral configuration unchanged.

Maintaining a public Docker image is recurring work: tracking upstream changes, reviewing installer diffs, fixing CI, updating dependencies, checking Docker Hub publication and keeping the documentation honest.

If this image saves you time or makes you more confident running EarnApp in Docker, keeping the maintainer referral enabled helps support that work at no extra cost to you.

The project remains open source. You can inspect, fork and modify it. The request is simple: if you benefit from the maintained image, consider leaving the referral in place.
